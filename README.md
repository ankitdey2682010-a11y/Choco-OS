#  Chocolate OS 

> A sweet, web-based desktop operating system simulation crafted with rich chocolate aesthetics, glassmorphism UI, built-in mini-apps, and a custom Web Audio synthesizer.

##  Features

*  **Desktop Experience**
*  **Built-in  Applications**:
  *  **Cocoa Craft Tycoon**
  *  **Choco Canvas Studio**
  *  **Lo-Fi Beats**
  *  **Choco Swap Match-3**
  *  **Recipes & Notes**
  *  **Sweet Calculator**
  *  **Cocoa Shell CLI**

* **Custom Theme**: CSS effects (`choco-panel`).
